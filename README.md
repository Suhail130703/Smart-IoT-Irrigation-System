# Smart IoT Irrigation System

## Project Overview
An IoT-based smart irrigation system developed using the LPC2148 microcontroller. The system monitors environmental conditions and soil moisture levels to support automatic irrigation and remote monitoring.

## Hardware Components
- LPC2148 Microcontroller
- DHT11 Temperature and Humidity Sensor
- Soil Moisture Sensor
- ESP-01 (ESP8266-based Wi-Fi Module)
- LCD Display
- Water Pump

## Communication and IoT
- ESP-01 Wi-Fi module for wireless connectivity.
- ThingSpeak cloud for uploading environmental sensor data.

## Key Features
- Monitors temperature and relative humidity using the DHT11 sensor.
- Measures soil moisture levels.
- Displays sensor readings on the LCD.
- Uploads environmental data to the ThingSpeak cloud.
- Automatically controls the water pump based on soil moisture readings.

## Development Environment
- Embedded C
- LPC2148
- Embedded Systems Development Tools

## Project Objective
To monitor field conditions through IoT and automate irrigation based on soil moisture levels, helping reduce unnecessary water usage.
